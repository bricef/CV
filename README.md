# CV
Latex source file and pdf output for my CV.

`make` builds `Brice-Fernandes-CV.pdf`. `make no-keywords` builds `Brice-Fernandes-CV-no-keywords.pdf`, the same CV without the keyword lines under each role, for comparing the two.
